# DICCIONARIO

## Propósito
Diccionario de variables del tablero TABLERO DE ATENCIONES INSTITUCIONALES: qué es cada tabla, medida, columna y relación del modelo, con su cálculo y dónde se usa. Las tablas históricas mensuales vienen de un libro Excel y el resto de la bodega DWSES. Lo que no se pudo sustentar con el modelo, el DAX o la documentación queda marcado «Por confirmar» y resumido en Observaciones.

## Tablas
- **ASEGURADORAS**: Planes de beneficio (GENDETCON) con su tercero; se relaciona con gineco, referencia, imágenes antiguas y estancia. Origen: consulta SQL sobre DIM_ASEGURADORA, GENTERCER_DW en la base DWSES (Import). Granularidad: Una fila por plan de beneficio (OID de GENDETCON). Columnas principales: ASEGURADORA_OK, GDECODIGO, GDENOMBRE, GDETIPREG, GENCONTRA1, GENTERCER1, NOMBRE_TERCERO, OID.
- **ATENCION DOMICILIARIA**: Todas las filas de la vista ATC_DOMICILIARIA (estancias en camas de hospitalización en casa con ingreso, cama, servicio, fechas de ingreso y egreso de cama, días de estancia, aseguradora, plan, diagnóstico CIE10, CMD, GRD y municipio), más FECHA = fecha de…. Origen: consulta SQL sobre ATC_DOMICILIARIA en la base DWSES (Import). Granularidad: Una fila por estancia en cama de hospitalización en casa (ingreso y cama). Columnas principales: AEEGRCORCU, AINCONSEC, ANNO, CAMA, CIE10, CMD, CODCMD, CODGRD y 23 más.
- **ATENCIONES_GINECO**: Ingresos desde 2023-01-01 hasta hoy con causa de ingreso 9 (maternidad), uno por paciente, ingreso y fecha; trae número de ingreso, plan de beneficio, fecha y hora de ingreso y aseguradora agrupada. Origen: consulta SQL sobre DIM_INGRESO, DIM_ASEGURADORA, DIM_PACIENTES en la base DWSES (Import). Granularidad: Una fila por ingreso por maternidad (paciente, ingreso y fecha). Columnas principales: ASEGURADORA, GDENOMBRE, HORA_INGRESO, MES_INGRESO, NUM_INGRESO, OID_ASEGURADORA, PACNUMDOC.
- **ATENCIONES_IMAGENES**: Totales mensuales históricos de atenciones de imágenes por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; sirven para proyecciones. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: ATENCIONES IMAGENES, AÑO, FECHA, MES, Mes_Numero.
- **ATENCIONES_LABORATORIO**: Totales mensuales históricos de atenciones de laboratorio por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; sirven para proyecciones. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: ATENCIONES LABORATORIO, AÑO, FECHA, MES, Mes_Numero.
- **Calendario**: Tabla de fechas calculada con CALENDAR desde 2023-01-01 hasta el 31 de diciembre del año en curso, con columnas AÑO, MES y AñoMes; filtra casi todas las páginas por Año y Mes. Origen: tabla calculada con DAX `CALENDAR("2023-01-01",DATE(YEAR(TODAY()),12,31))` (Import). Granularidad: Una fila por día desde 2023-01-01 hasta el 31 de diciembre del año en curso. Columnas principales: Date, Año, AñoMes, Mes.
- **CAMAS**: Catálogo de camas (DIM_CAMAS) con código, nombre, estado y unidad (HPNSUBGRU) a la que pertenecen. Origen: consulta SQL sobre DIM_CAMAS en la base DWSES (Import). Granularidad: Una fila por cama. Columnas principales: ADNINGRESO, HCACODIGO, HCAESTADO, HCANOMBRE, HPNSUBGRU, OID.
- **CAMAS HABILITADAS**: Estado diario de las camas de la bodega (tabla estados_camas) con código de cama, servicio, estado y fecha; permite contar camas habilitadas en [GIRO_CAMA_HB]. Origen: consulta SQL sobre [dwses].[dbo].[estados_camas] en la base DWSES (Import). Granularidad: Una fila por cama y fecha de estado (codcama y fechades). Columnas principales: codcama, codigo, estado, Estado_Dia, fechades, oid, servicio, Veces.
- **CIRUGIAS**: Cirugías realizadas (vista CIRUGIAS_DWSES) con su ingreso, aseguradora y EPS; FECHA es la fecha de la cirugía sin hora. La consulta no tiene filtro de fechas (el filtro está comentado). Origen: consulta SQL sobre CIRUGIAS_DWSES, DIM_INGRESO, DIM_ASEGURADORA, GENTERCER_DW en la base DWSES (Import). Granularidad: Una fila por cirugía realizada (las medidas cuentan CUPS o cédula). Columnas principales: ADNEGRESO, AIINGCORCU, AINCAUING, AINCONSEC, AINESTADO, AINFECING, AINTIPING, AINTIPRIE y 45 más.
- **CIRUGIAS_ARC**: Totales mensuales históricos de cirugías por año y mes (años anteriores), cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan las proyecciones de cirugías. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, CIRUGIAS, FECHA, MES, Mes_Numero.
- **CIRUGIAS_PENDIENTES**: Solicitudes de cirugía programada (TipoCirugiaOid = 1) planeadas desde 2025-01-01, con paciente, EPS, especialidad, procedimientos agrupados, médico, ESTADO ACTUAL y la primera fecha de cada estado quirúrgico. FECHA es la fecha en que se planeó. Origen: consulta SQL sobre PLANILLAUSUARIO.DBO.Qx_HistorialSolicitud, PLANILLAUSUARIO.DBO.Qx_ProcedimientoCirugia, PLANILLAUSUARIO.DBO.Qx_Procedimiento, PLANILLAUSUARIO.DBO.Qx_SolicitudProgramacion, Historial en la base DWSES (Import). Granularidad: Una fila por solicitud de cirugía programada. Columnas principales: ESTADO ACTUAL, Documentación Entregada por Facturación, DOCUMENTO, EPS, ESPECIALIDAD, FECHA, MEDICO, NOMBRE y 16 más.
- **CONSOLIDADO_IMAGENES_2025**: La misma tabla de la página IMAGENES; el área sale de la columna AREA_SERVICIO. Origen: consulta SQL sobre CONSOLIDADO_IMAGENES_DWSES, DIM_INGRESO, DIM_PACIENTES en la base DWSES (Import). Granularidad: Una fila por estudio de imagen con su cantidad. Columnas principales: AREA_SERVICIO, CANTIDAD, CEDULA, CODIGO, EDAD, ENTIDAD, EXAMEN, FECHA y 5 más.
- **CONSULTA_AMBULATORIAS**: Totales históricos de atenciones ambulatorias por año y mes; la usa la proyección. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: ATENCIONES AMBULATORIAS, AÑO, FECHA, MES, Mes_Numero.
- **CONSULTA_URGENCIAS**: La misma tabla de la página URGENCIAS (consultas médicas de urgencias con triage, clasificación, grupo de edad y aseguradora). Origen: consulta SQL sobre DIM_INGRESO, DIM_TRIAGE, DIM_HCNCLAURGTR, DIM_HCNCONTRDT, DIM_ASEGURADORA en la base DWSES (Import). Granularidad: Una fila por ingreso por urgencias con triage y consulta médica. Columnas principales: CLASIFICACION_TRIAGE, FECHA_ADMISION, FECHA_FOLIO, SERVICIO_ATENCION, AGRUPA_ASEGURADORA, CAUSA_INGRESO, DIACODIGO, DIANOMBRE y 13 más.
- **CONSULTAS PRIORITARIAS**: Citas médicas desde 2024-01-01 hasta el último día del mes anterior cuyo tipo de atención contiene «PRIORI», no canceladas y con folio de historia clínica el mismo día; trae asegurador, especialidad, médico, fecha de la cita, tipo de atención y estado. Origen: consulta SQL sobre CITAS_MEDICAS, DIM_FOLIO, DIM_PACIENTES, DIM_MEDICO, DIM_ESPECIALIDAD en la base DWSES (Import). Granularidad: Una fila por cita prioritaria atendida. Columnas principales: ASEGURADOR, IDENTIFICACION, ESPECIALIDAD, ESTADO_CITA, FECHA, FECHA_CITA, MEDICO, PACIENTE y 2 más.
- **CONSULTAS SIN TRIAGE**: Ingresos por urgencias (AINURGCON = 0) del área 2 (urgencias) desde 2024-01-01 hasta hoy, con su triage si existe, hora de llegada, admisión, primer folio y clasificación; CLASIFICACION_TRIAGE vale SIN TRIAGE cuando el ingreso no tiene triage. Origen: consulta SQL sobre DIM_INGRESO, DIM_TRIAGE, DIM_HCNCLAURGTR, DIM_MEDICO, DIM_DIAGNOSTICO en la base DWSES (Import). Granularidad: Una fila por ingreso por urgencias, con o sin triage. Columnas principales: AINCONSEC, CLASIFICACION_TRIAGE, DOCUMENTO, ENTNOMBRE, FECHA, FECHA_ADMISION, FECHA_TRIAGE, LLEGADA_PORTERO y 4 más.
- **CONSULTAS_AMBULATORIAS**: Citas médicas desde 2025-11-01 con folio de historia clínica el mismo día, unidas a la tabla histórica AT_AMB_MAYO_2025 (periodo que cubre por confirmar). Origen: consulta SQL sobre CITAS_MEDICAS, DIM_INGRESO, DIM_FOLIO, DIM_PACIENTES, DIM_MEDICO en la base DWSES (Import). Granularidad: Una fila por cita médica ambulatoria. Columnas principales: ASEGURADOR, ESPECIALIDAD, ESTADO_CITA, PV_CONTROL, CONSULTA_PRA, CONTROL, DIAS, DIAS_REAL y 10 más.
- **DIAS_ESTANCIA**: Estancias por cama leídas del sistema Dinámica (HPNESTANC, camas, ingresos y pacientes) con diagnóstico, entidad, fechas y días de estancia; desde el 2026-07-01 reemplaza a FACT_EGRESOS en egresos y estancia de [Total_Egresos_Unificado] y [DIAS_ESTANCIA_TOTAL]. Origen: consulta SQL sobre [DGempres10].dbo.HPNESTANC, [DGempres10].dbo.HPNDEFCAM, [DGempres10].dbo.ADNINGRESO, [DGempres10].dbo.GENDETCON, [DGempres10].dbo.GENPACIEN en la base DWSES (Import). Granularidad: Una fila por estancia en cama (ingreso y cama). Columnas principales: CAMA, CEDULA, CODIGO_DX, CODIGO_EPS, DIAGNOSTICO, DIFERENCIA_DIAS, EGRESO_CAMA, ENTIDAD y 10 más.
- **DIM_ASEGURADOR**: Lista de aseguradores sin repetir, tomada de las entidades de FACT_EGRESOS y FACT_ESTANCIA. No tiene relaciones con otras tablas. Origen: tabla calculada con DAX `DISTINCT( UNION( SELECTCOLUMNS(FACT_EGRESOS, "ASEGURADOR", FACT_EGRESOS[ENTIDAD]), SELECTCOLUMNS(FACT_ESTANCIA, "ASEGURADOR", FACT_ESTANCIA…` (Import). Granularidad: Una fila por asegurador. Columnas principales: ASEGURADOR.
- **DIM_SERVICIO**: Servicios homologados (SERVICIO_HOMOLOGADO) que unen egresos, estancia y ocupación. Origen: consulta SQL sobre PLANILLAUSUARIO.DBO.TABLEROGRD, DGEMPRES10.DBO.HPNESTANC, DGEMPRES10.DBO.HPNDEFCAM, DGEMPRES10.DBO.HPNSUBGRU, #HPN_BASE en la base DWSES (Import). Granularidad: Una fila por servicio homologado. Columnas principales: SERVICIO_HOMOLOGADO.
- **EGRESOS**: Totales mensuales históricos de egresos de los pisos de hospitalización por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan [Proyeccion_Egresos_Mensual_Visible]. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, EGRESOS, FECHA, MES, Mes_Numero.
- **EGRESOS Y TRASLADOS**: Egresos y traslados de pacientes (vista TRASLADOS_Y_EGRESOS) con ingreso, cama, servicio, diagnóstico CIE10, CMD, GRD y días de estancia; la columna EGRESO marca cuáles movimientos son egresos. Origen: consulta SQL sobre TRASLADOS_Y_EGRESOS en la base DWSES (Import). Granularidad: Una fila por movimiento (egreso o traslado) de un ingreso. Columnas principales: AEEGRCORCU, AINCONSEC, ANNO, CAMA, CIE10, CMD, CODCMD, CODGRD y 24 más.
- **EGRESOS_GINECO**: Totales mensuales históricos de egresos de obstetricia por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan [Proyeccion_Egresos_Mensual_Visible]. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, EGRESOS GINECO, FECHA, MES, Mes_Numero.
- **EGRESOS_NEONATOS**: Totales mensuales históricos de egresos de hospitalización de neonatos por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan [Proyeccion_Egresos_Mensual_Visible]. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, EGRESOS NEONATOS, FECHA, MES, Mes_Numero.
- **EGRESOS_POR_SERVICIO**: Egresos y traslados por servicio, unidos de tres fuentes (egresos hasta junio de 2025, traslados de junio de 2025 y la vista TRASLADOS_Y_EGRESOS) con ingreso, cama, servicio, aseguradora, diagnóstico, fechas, días y tipo (PUERTA o TRASLADO). Origen: consulta SQL sobre TRASLADOS_JUNIO_2025, DIM_ASEGURADORA, GENTERCER_DW, TRASLADOS_Y_EGRESOS, EGRESOS_HASTA_JUNIO_2025 en la base DWSES (Import). Granularidad: Una fila por egreso o traslado de un ingreso desde un servicio. Columnas principales: TERNOMCOM, CAMA, DIAGNOSTICO, DIAS, FECHA_EGRESO, FECHA_INGRESO, IDENTIFICACION, INGRESO y 4 más.
- **EGRESOS_UCI**: Totales mensuales históricos de egresos de cuidado intensivo e intermedio por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan [Proyeccion_Egresos_Mensual_Visible]. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, EGRESOS UCI, FECHA, MES, Mes_Numero.
- **EGRESOS_URGENCIAS**: Totales mensuales históricos de egresos de urgencias por año y mes, cargados del libro Excel DATOS EPIDEMIOLOGIA; alimentan [Proyeccion_Egresos_Mensual_Visible]. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes (totales mensuales cargados de un libro Excel). Columnas principales: AÑO, EGRESOS URGENCIAS, FECHA, MES, Mes_Numero.
- **FACT_EGRESOS**: Egresos con ingreso, entidad, cama, servicio, servicio homologado, tipo de egreso (EGRESO_PUERTA) y fechas de epicrisis y de facturación; se une al Calendario por la fecha de egreso de facturación. Origen: consulta SQL sobre DWSES.DBO.TRASLADOS_Y_EGRESOS, base, PLANILLAUSUARIO.DBO.TABLEROGRD, DGEMPRES10.DBO.GENDIAGNO, PLANILLAUSUARIO.DBO.TbRelacionDiag en la base DWSES (Import). Granularidad: Una fila por egreso. Columnas principales: SERVICIO, CAMA, CODIGO, CODIGO_DIAGNOSTICO, DIAGNOSTICO, DIAS_ESTANCIA, EGRESO_EPICRISIS, EGRESO_FACTURACION y 9 más.
- **FACT_ESTANCIA**: Estancias por cama con días y horas de estancia y servicio homologado. Origen: consulta SQL sobre FACT_ESTANCIA, DIM_CAMAS, DIM_INGRESO, DIM_ASEGURADORA, DIM_PACIENTES en la base DWSES (Import). Granularidad: Una fila por estancia en cama. Columnas principales: CAMA, CEDULA, CODIGO_CIE10, CODIGO_ENTIDAD, DIAGNOSTICO, DIAS_ESTANCIA, EGRESO_CAMA, EGRESO_CAMA_FECHA y 10 más.
- **Hoja1**: Hoja del libro Excel DATOS EPIDEMIOLOGIA con una columna de totales mensuales por serie (atenciones ambulatorias, imágenes, laboratorio, egresos y otras) y sus años y meses. Ninguna medida del modelo la usa. Origen: consulta de Power Query (M) (Import). Granularidad: Una fila por año y mes. Columnas principales: ATENCIONES AMBULATORIAS, ATENCIONES IMAGENES, ATENCIONES LABORATORIO, AÑO, AÑO_1, AÑO_11, AÑO_13, AÑO_15 y 27 más.
- **HOSPITALIZACION_PARCIAL**: Todas las filas de la vista ATC_HOSPI_PARCIAL (estancias en camas de hospitalización parcial con ingreso, cama, fechas de ingreso y egreso, días de estancia, aseguradora, diagnóstico CIE10, CMD y GRD); FECHA es la fecha de ingreso a la cama, sin hora. Origen: consulta SQL sobre ATC_HOSPI_PARCIAL en la base DWSES (Import). Granularidad: Una fila por estancia en cama de hospitalización parcial (ingreso y cama). Columnas principales: AEEGRCORCU, AINCONSEC, ANNO, CAMA, CIE10, CMD, CODCMD, CODGRD y 23 más.
- **IMAGENES_CARDIOLOGIA**: Estudios de cardiología (servicios de imagen de SLNSERPRO y SLNSERHOJ) con aseguradora, fecha y marcas de tipo de ingreso AMBULATORIO u HOSPITALARIO. Tabla antigua; la página IMAGENES usa CONSOLIDADO_IMAGENES_2025. Origen: consulta SQL sobre HCNRESSVFC, SLNSERHOJ, SLNSERPRO, DIM_GENSERIPS, AREA_SERVICIO en la base DWSES (Import). Granularidad: Una fila por estudio de cardiología. Columnas principales: AMBULATORIO_CARDIO, ASEGURADORA_OK, CARDIOLOGIA, ENTIDAD, FECHA, GCFNOMBRE, GGRNOMBRE, GSUNOMBRE y 8 más.
- **IMAGENES_ECOGRAFIA**: Estudios de ecografía (servicios de imagen de SLNSERPRO y SLNSERHOJ) con aseguradora, fecha y marcas de tipo de ingreso AMBULATORIO u HOSPITALARIO. Tabla antigua; la página IMAGENES usa CONSOLIDADO_IMAGENES_2025. Origen: consulta SQL sobre HCNRESSVFC, SLNSERHOJ, SLNSERPRO, DIM_GENSERIPS, AREA_SERVICIO en la base DWSES (Import). Granularidad: Una fila por estudio de ecografía. Columnas principales: AMBULATORIO_ECO, AREA DE SERVICIO, ASEGURADORA_OK, ENTIDAD, FECHA, gascodigo, GCFNOMBRE, GGRNOMBRE y 10 más.
- **IMAGENES_OTRAS**: Otros estudios de imagen (servicios de imagen de SLNSERPRO y SLNSERHOJ) con aseguradora, fecha y marcas de tipo de ingreso AMBULATORIO u HOSPITALARIO. Tabla antigua; la página IMAGENES usa CONSOLIDADO_IMAGENES_2025. Origen: consulta SQL sobre HCNRESSVFC, SLNSERHOJ, SLNSERPRO, DIM_GENSERIPS, AREA_SERVICIO en la base DWSES (Import). Granularidad: Una fila por estudio de imagen. Columnas principales: AMBULATORIO_OTRAS, AREA DE SERVICIO, ASEGURADORA_OK, ENTIDAD, FECHA, GCFNOMBRE, GGRNOMBRE, GSUNOMBRE y 8 más.
- **LABORATORIOS**: Servicios prestados en el área de laboratorio (área 15) desde 2025-01-01 hasta hoy, sin ingresos con AINESTADO 2 o 4; trae paciente, código y CUPS del examen, nombre del servicio, fecha de atención, tipo de ingreso (AMBULATORIO u HOSPITALARIO), vía de…. Origen: consulta SQL sobre SLNSERPRO, AREA_SERVICIO, DIM_INGRESO, DIM_PACIENTES, SLNSERHOJ en la base DWSES (Import). Granularidad: Una fila por servicio de laboratorio prestado. Columnas principales: ASEGURADOR, CODIGO, CUPS, FECHA_ATENCION, IDENTIFICACION, INGRESO POR, PACIENTE, SERVICIO IPS y 1 más.
- **LABORATORIOS_PATOLOGICOS**: Solicitudes de patología desde 2025-01-01 hasta hoy (por fecha de solicitud) con su primer resultado del laboratorio de patología en estado 1, 2 o 3; trae consecutivo del ingreso, fecha de solicitud, fecha de realizado, código y tipo de examen, resultado…. Origen: consulta SQL sobre DGempres10..HCNSOLPAT, LabPatologico..Resultados, DGempres10..ADNINGRESO, DGempres10..GENPACIEN, DGempres10..GENDETCON en la base dwses (Import). Granularidad: Una fila por solicitud de patología con su primer resultado. Columnas principales: Aseguradora, Consecutivo, FechaSolicitud, TipoLaboratorio, CategoriaEPS, CodigoLaboratorio, FechaRealizado, Paciente y 1 más.
- **MostrarProyeccion**: Tabla fija con las opciones «SI» y «No» que alimenta las casillas «Mostrar proyección». Origen: tabla calculada con DAX `DATATABLE ( "Opcion", STRING, { { "SI" }, { "No" } } )` (Import). Granularidad: Dos filas (SI y No). Columnas principales: Opcion.
- **OBSERVADOS**: Ingresos desde 2022-01-01 hasta hoy de tipo ambulatorio (AINTIPING = 1) que entran por urgencias (AINURGCON = 0) en las áreas 2 (urgencias) y 42 (gineco-obstetricia), con documento, aseguradora agrupada, fecha de ingreso, triage asociado (HCENTRIAGE) y grupo…. Origen: consulta SQL sobre DIM_INGRESO, DIM_PACIENTES, DIM_ASEGURADORA, AREA_SERVICIO, GENTERCER_DW en la base DWSES (Import). Granularidad: Una fila por ingreso en observación. Columnas principales: ASEGURADORA, fecha, FECHA_INGRESO, GASNOMBRE, GDENOMBRE, GENPACIEN, GENTERCER1, HCENTRIAGE y 4 más.
- **OPORTUNIDAD CIRUGIA**: Solicitudes de cirugía programada (TipoCirugiaOid = 1) planeadas desde 2025-01-01, con la primera fecha en que pasaron por cada estado quirúrgico. Su columna calculada OPORTUNIDAD mide los días entre estados; la página CIRUGÍAS la usa para el tiempo de oportunidad de la cirugía ambulatoria (por confirmar). Origen: consulta SQL sobre PLANILLAUSUARIO.DBO.Qx_HistorialSolicitud, PLANILLAUSUARIO.DBO.Qx_ProcedimientoCirugia, PLANILLAUSUARIO.DBO.Qx_Procedimiento, PLANILLAUSUARIO.DBO.Qx_SolicitudProgramacion, Historial en la base DWSES (Import). Granularidad: Una fila por solicitud de cirugía programada. Columnas principales: Documentación Entregada por Facturación, DOCUMENTO, EPS, ESPECIALIDAD, ESTADO ACTUAL, FECHA, MEDICO, NOMBRE y 17 más.
- **OPORTUNIDAD_TRIAGE**: La misma tabla de la página TRIAGE: triages desde 2023-01-01, sin el código UA, con la columna MENORES (grupo de edad según la edad registrada en el triage). Origen: consulta SQL sobre DIM_TRIAGE, DIM_ENTIDAD, DIM_HCNCLAURGTR, DIM_HCNCONTRDT, GENTERCER_DW en la base DWSES (Import). Granularidad: Una fila por triage. Columnas principales: DESCRI_TRIGE, ASEGURADORA, AÑO, CLASIFICACION_TRIAGE, DIA_SEMANA, ENTNOMBRE, FECHA, FECHA_TRIAGE y 18 más.

## Medidas
- **[PROMEDIO_MENSUAL]**: Promedio mensual de consultas prioritarias del año en curso: las del año divididas entre el número del mes actual. Unidad: consultas por mes. Tabla: CONSULTAS PRIORITARIAS. Cálculo: `DIVIDE([AÑO_ACTUAL],MONTH(TODAY()))`. Se usa en: CONSULTAS PRIORITARIAS › Tarjeta «PROMEDIO MENSUAL».
- **[Promedio_Dinamico]**: Oportunidad de la consulta ambulatoria: promedio de días entre la fecha en que se asigna la cita y la fecha de la cita. Con filtro de fecha usa el periodo elegido; sin filtro usa el último mes cerrado. Alimenta los medidores de primera vez y de control. Unidad: días. Tabla: CONSULTAS_AMBULATORIAS. Cálculo: `VAR FiltroActivo = ISFILTERED('Calendario'[Date]) || ISFILTERED('Calendario'[Date].[Mes]) && ISFILTERED('Calendario'[Date].[Año]) VAR Hoy = TODAY() VAR PrimerDiaMesActual = DATE(YEAR(Hoy), MONTH(Hoy), 1) VAR UltimoDiaMesCerrado = PrimerDiaMesActual - 1 VAR MesCerrado = MONTH(UltimoDiaMesCerrado) VAR AnioCerrado = YEAR(UltimoDiaMesCerrado) RETURN IF( FiltroActivo, [promedio_asignacion], CALCULATE( [promedio_asignacion], MONTH('Calendario'[Date]) = MesCerrado, YEAR('Calendario'[Date]) = AnioCerrado ) )`. Se usa en: DETALLE ESPECIALIDADES › Medidor «OPORTUNIDAD CONSULTA CONTROL»; DETALLE ESPECIALIDADES › Medidor «OPORTUNIDAD CONSULTA PRIMERA VEZ».
- **[GIRO_CAMA1]**: Giro cama de INDICADORES: egresos del año (el actual si el año elegido es el actual, si no el anterior) divididos entre el total de camas de los servicios visibles. No filtra el tipo de egreso. Unidad: egresos por cama. Tabla: FACT_EGRESOS. Cálculo: `VAR EgresosNumerador = IF( SELECTEDVALUE('Calendario'[Año]) = YEAR(TODAY()), [AÑO ACTUAL1], [AÑO ANTERIOR1] ) VAR TotalCamas = SUMX( VALUES(FACT_EGRESOS[SERVICIO_HOMOLOGADO]), [NUM_CAM_EGRESOS] ) RETURN DIVIDE(EgresosNumerador, TotalCamas, 0)`. Se usa en: INDICADORES › Gráfico de líneas «GIRO CAMA».
- **[Promedio_Laboratorio_pat]**: Promedio mensual de reportes de patología del año elegido o, sin año elegido, del año cerrado; solo promedia los meses con reportes. Unidad: reportes por mes. Tabla: LABORATORIOS_PATOLOGICOS. Cálculo: `VAR Hoy = TODAY() VAR AnioCerrado = YEAR(Hoy) - 1 VAR AnioContexto = SELECTEDVALUE('Calendario'[Año], AnioCerrado) VAR PromedioMensual = CALCULATE( AVERAGEX( FILTER( VALUES('Calendario'[Mes]), [TOTAL_LABORATORIO_PAT] > 0 ), [TOTAL_LABORATORIO_PAT] ), 'Calendario'[Año] = AnioContexto ) RETURN PromedioMensual`. Se usa en: LABORATORIO PATOLOGICO › Tarjeta «PROMEDIO MENSUAL».
- **[ATEN_DOM2024]**: Atenciones domiciliarias de 2024; el año está escrito en la fórmula. Auxiliar de la proyección. Unidad: atenciones. Tabla: ATENCION DOMICILIARIA. Clase: auxiliar. Cálculo: `CALCULATE( [ATENCION_DM], Calendario[Año] = 2024 )`. Se usa en: las medidas [PROYECCION_ATD].
- **[ATEN_DOM2025]**: Atenciones domiciliarias de 2025; el año está escrito en la fórmula. Auxiliar de la proyección. Unidad: atenciones. Tabla: ATENCION DOMICILIARIA. Clase: auxiliar. Cálculo: `CALCULATE( [ATENCION_DM], Calendario[Año] = 2025 )`. Se usa en: las medidas [PROYECCION_ATD].
- **[ATEN_DOM2026]**: Atenciones domiciliarias de 2026; el año está escrito en la fórmula. Auxiliar de la proyección. Unidad: atenciones. Tabla: ATENCION DOMICILIARIA. Cálculo: `CALCULATE( [ATENCION_DM], Calendario[Año] = 2026 )`. Se usa en: no aparece en visuales ni filtros del informe.
- **[ATENCION_DM]**: Número de atenciones domiciliarias (filas de ATENCION DOMICILIARIA, una por estancia en cama de hospitalización en casa). Unidad: atenciones. Tabla: ATENCION DOMICILIARIA. Clase: auxiliar. Cálculo: `COUNTROWS( 'ATENCION DOMICILIARIA' )`. Se usa en: las medidas [ATEN_DOM2024], [ATEN_DOM2025], [ATEN_DOM2026].
- **[PROM_ATENCION_AD]**: Promedio mensual de atenciones domiciliarias: ingresos del año divididos entre 12; sin filtro de tiempo usa el año anterior al último del modelo y con varios años suma los promedios por año. Unidad: atenciones por mes. Tabla: ATENCION DOMICILIARIA. Cálculo: `VAR MaxYearModelo = CALCULATE ( MAX ( Calendario[Año] ), ALL ( Calendario ) ) VAR HayFiltroTiempo = ISCROSSFILTERED ( Calendario[Date] ) || ISFILTERED ( Calendario[Año] ) || ISFILTERED ( Calendario[Mes] ) VAR AniosSel = FILTER ( VALUES ( Calendario[Año] ), NOT ISBLANK ( Calendario[Año] ) ) RETURN IF ( NOT HayFiltroTiempo, CALCULATE ( DIVIDE ( COUNT ('ATENCION DOMICILIARIA'[INGRESO] ), 12, 0 ), Calendario[Año] = MaxYearModelo - 1 ), SUMX ( AniosSel, VAR AnioActual = Calendario[Año] RETURN CALCULATE ( DIVIDE ( COUNT ( 'ATENCION DOMICILIARIA'[INGRESO] ), 12, 0 ), KEEPFILTERS ( Calendario[Año] = AnioActual ) ) ) )`. Se usa en: no aparece en visuales ni filtros del informe.
- **[PROYECCION_ATD]**: Proyección mensual de atenciones domiciliarias: mismo mes del año anterior por (1 + variación entre los dos años anteriores). Solo con «Mostrar proyección» = SI. Usa las medidas de año fijo 2025 y 2024, por lo que no sigue el año elegido. Unidad: atenciones. Tabla: ATENCION DOMICILIARIA. Cálculo: `VAR AnnoSeleccionado = COALESCE ( SELECTEDVALUE ( Calendario[Año] ), 2026 ) VAR Mostrar = SELECTEDVALUE ( MostrarProyeccion[Opcion], "NO" ) VAR CalculoMensual = SUMX( VALUES( Calendario[Mes] ), VAR MesDeCalculo = Calendario[Mes] VAR AteAnterior = CALCULATE ( [ATEN_DOM2025], REMOVEFILTERS ( Calendario ), Calendario[Año] = AnnoSeleccionado - 1, Calendario[Mes] = MesDeCalculo ) VAR AteTrasAnterior = CALCULATE ( [ATEN_DOM2024], REMOVEFILTERS ( Calendario ), Calendario[Año] = AnnoSeleccionado - 2, Calendario[Mes] = MesDeCalculo ) VAR Crec = DIVIDE ( AteAnterior - AteTrasAnterior, AteTrasAnterior ) RETURN IF ( NOT ISBLANK ( AteAnterior ) && AteTrasAnterior <> 0, AteAnterior * ( 1 + Crec ) ) ) RETURN IF ( Mostrar = "SI", CalculoMensual )`. Se usa en: no aparece en visuales ni filtros del informe.
