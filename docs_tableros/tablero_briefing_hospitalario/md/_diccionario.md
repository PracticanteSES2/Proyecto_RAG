## Medidas
- **[%OCUPACION]**: Porcentaje de ocupación. Camas ocupadas sobre camas filtradas, en porcentaje. Unidad: Por confirmar. Tabla: CAMAS DISPONIBLES. Cálculo: `DIVIDE( SUM('CAMAS DISPONIBLES'[OCUPADAS]), CALCULATE( DISTINCTCOUNT('CAMAS DISPONIBLES'[HCACODIGO]), FILTER( 'CAMAS DISPONIBLES', NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "EXP") && NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "OH") && 'CAMAS DISPONIBLES'[MOSTRAR] = "MOSTRAR" && 'CAMAS DISPONIBLES'[MOSTRAR_6TO] <> 0 && 'CAMAS DISPONIBLES'[HCACODIGO] <> "321" && 'CAMAS DISPONIBLES'[HCACODIGO] <> "322" ) ) )`. Se usa en: INICIO › Gráfico combinado de líneas y columnas «%OCUPACIÓN POR SERVICIO»; GESTIÓN CAMAS › Tarjeta «%OCUPACION».
- **[CamasFiltradas]**: Por confirmar. Unidad: Por confirmar. Tabla: CAMAS DISPONIBLES. Cálculo: `CALCULATE( DISTINCTCOUNT('CAMAS DISPONIBLES'[HCACODIGO]), FILTER( 'CAMAS DISPONIBLES', NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "EXP") && NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "OH") && 'CAMAS DISPONIBLES'[MOSTRAR] = "MOSTRAR" && 'CAMAS DISPONIBLES'[MOSTRAR_6TO] <> 0 && 'CAMAS DISPONIBLES'[HCACODIGO] <> "321" && 'CAMAS DISPONIBLES'[HCACODIGO] <> "322" ) )`. Se usa en: INICIO › Gráfico combinado de líneas y columnas «%OCUPACIÓN POR SERVICIO».
- **[TextoConResultadoHTML]**: Por confirmar. Unidad: Por confirmar. Tabla: NEDOCS. Cálculo: `VAR A1 = SUM(NEDOCS[A1]) VAR A2 = SUM(NEDOCS[A2]) VAR B1 = SUM(NEDOCS[B1]) VAR B2 = SUM(NEDOCS[B2]) VAR C = SUM(NEDOCS[C]) VAR D = SUM(NEDOCS[D]) VAR E = SUM(NEDOCS[E]) VAR TotalN = -20 + IF(A2 <> 0, 85.8 * (A1 / A2), 0) + IF(B2 <> 0, 600 * (B1 / B2), 0) + 5.64 * C + 0.93 * D + 13.4 * E RETURN "<b>NEDOCS</b> = -20 + 85.8 * (<span style='color:red'>" & FORMAT(A1, "0") & "</span> / <span style='color:red'>" & FORMAT(A2, "0") & "</span>) + 600 * (<span style='color:red'>" & FORMAT(B1, "0") & "</span> / <span style='color:red'>" & FORMAT(B2, "0") & "</span>) + 5.64 * <span style='color:red'>" & FORMAT(C, "0") & "</span> + 0.93 * <span style='color:red'>" & FORMAT(D, "0") & "</span> + 13.4 * <span style='color:red'>" & FORMAT(E, "0") & "</span> = <b>" & FORMAT(TotalN, "0.00") & "</b>"`. Se usa en: DETALLE NEDOCS › Visual HTML (personalizado) «TextoConResultadoHTML».
- **[TotalN]**: NEDOCS. Puntaje de sobreocupación de urgencias. Unidad: Por confirmar. Tabla: NEDOCS. Cálculo: `(-20 + 85.8 * (SUM(NEDOCS[A1]) / SUM(NEDOCS[A2])) + 600 * (SUM(NEDOCS[B1]) / SUM(NEDOCS[B2])) + 5.64 * SUM(NEDOCS[C]) + 0.93 * SUM(NEDOCS[D]) + 13.4 * SUM(NEDOCS[E]))`. Se usa en: INICIO › Tarjeta «NEDOCS»; DETALLE NEDOCS › Tarjeta «NEDOCS».
- **[TieneDatos]**: Por confirmar. Unidad: Por confirmar. Tabla: TablaFechas. Cálculo: `IF( CALCULATE(COUNTROWS('EGRESOS PROBABLES'), USERELATIONSHIP(TablaFechas[Date], 'EGRESOS PROBABLES'[FechaSalida])) > 0, 1, 0 )`. Se usa en: EGRESOS PROBABLES › Segmentación de TablaFechas[Año]; EGRESOS PROBABLES › Segmentación de TablaFechas[Mes]; EGRESOS PROBABLES › Segmentación de TablaFechas[Dia].
- **[TOTAL_OCUPADAS]**: Por confirmar. Unidad: Por confirmar. Tabla: CAMAS DISPONIBLES. Cálculo: `CALCULATE( DISTINCTCOUNT('CAMAS DISPONIBLES'[HCACODIGO]), FILTER( 'CAMAS DISPONIBLES', 'CAMAS DISPONIBLES'[MOSTRAR] = "MOSTRAR" && 'CAMAS DISPONIBLES'[MOSTRAR_6TO] <> 0 && 'CAMAS DISPONIBLES'[HCACODIGO] <> "321" && 'CAMAS DISPONIBLES'[HCACODIGO] <> "322" && ('CAMAS DISPONIBLES'[ESTADO] = 2 || 'CAMAS DISPONIBLES'[ESTADO] = 100) ) )`. Se usa en: no aparece en visuales ni filtros del informe.

## Relaciones
