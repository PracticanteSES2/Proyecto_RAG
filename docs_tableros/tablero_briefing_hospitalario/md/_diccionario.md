# DICCIONARIO

## Propósito
Diccionario de variables del tablero BRIEFING HOSPITALARIO: qué es cada tabla, medida y columna clave del modelo «BRIEFING HOSPITALARIO», con su cálculo y dónde se usa. Se genera del modelo y de los visuales; las descripciones de negocio marcadas «Por confirmar» las completa quien conoce el tablero. Las columnas están en _diccionario_columnas.md.

## Medidas
- **[%OCUPACION]**: Porcentaje de ocupación. Camas ocupadas sobre camas filtradas, en porcentaje. Unidad: porcentaje de camas. Tabla: CAMAS DISPONIBLES. Cálculo: `DIVIDE( SUM('CAMAS DISPONIBLES'[OCUPADAS]), CALCULATE( DISTINCTCOUNT('CAMAS DISPONIBLES'[HCACODIGO]), FILTER( 'CAMAS DISPONIBLES', NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "EXP") && NOT CONTAINSSTRING(LOWER('CAMAS DISPONIBLES'[HCACODIGO]), "OH") && 'CAMAS DISPONIBLES'[MOSTRAR] = "MOSTRAR" && 'CAMAS DISPONIBLES'[MOSTRAR_6TO] <> 0 && 'CAMAS DISPONIBLES'[HCACODIGO] <> "321" && 'CAMAS DISPONIBLES'[HCACODIGO] <> "322" ) ) )`. Se usa en: INICIO › Gráfico combinado de líneas y columnas «%OCUPACIÓN POR SERVICIO»; GESTIÓN CAMAS › Tarjeta «%OCUPACION».
